# ml-automation-explainability

Model explainability and fairness. SHAP, LIME, feature importance, model cards, fairness audits, and regulatory compliance documentation. Requires spark-core installed.

## Project tracking

This plugin's work is tracked in Jira project [PM3](https://blend360.atlassian.net/jira/core/projects/PM3/board). Filter the board by label `plugin:explainability` for this plugin's slice.
